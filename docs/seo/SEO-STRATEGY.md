# SEO Strategy

## Implementation status

The technical foundation and first explanatory cluster are live in the repository: city/type landing pages, query hubs, methodology, source disclosure and practical guides. Original quarterly reports, citations/mentions and performance decisions based on field data remain the next evidence-dependent stage.

Position the product as Taiwan's transparent, source-linked real-estate transaction research tool—not as a broker or listing marketplace.

Primary audiences: homebuyers, renters, property researchers and journalists. Primary conversions: successful searches, saved searches and repeat usage.

Content pillars:

1. City and district transaction-price pages.
2. Presale, resale and rental data explainers.
3. Data methodology and limitations.
4. Quarterly original market summaries.
5. Practical guides for reading transaction records.

KPIs: indexed canonical pages, non-brand impressions, successful organic search sessions, returning users, CWV pass rate, and attributed AI citations.
